# RO Toolbox v0.1.5 – What's New

## ✨ Smoother Updates
- **Automatic update check on startup** (silent in background)
- **One-click update action in header** when update is available
- **Manual check feedback improved**: "You are up to date." appears only when you click manually
- Improved restart behavior after installing updates

## 🎨 UI Improvements
- Settings modal refreshed to match main app styling
- **"Browse folder" renamed to "Set folder"**
- Removed **"Open item folder"** action from settings modal
- **Clear** action in settings is now less dominant
- Header now shows both:
  - **App version** (desktop shell)
  - **Backend version** (service version)

## 🧠 Better App Behavior
- App window height now adjusts more dynamically to content
- Toast notifications auto-hide instead of staying on screen forever
- Startup experience improved to reduce first-launch blank-screen/shutdown issues

## 📥 Installation / Update
Download and install using the latest MSI from Releases.  
If you're already installed, use the in-app updater from the header icon.
