# RO Toolbox v0.1.1 – What's New

## ✨ Easy Installation
We've made RO Toolbox way easier to install and use! Now it comes as a proper Windows installer (`.msi`) – just download and run. No more fiddling with configs.

## 🎨 Cleaner Interface
The app looks and feels much better:
- **Compact design** – Everything is more organized and takes up less space
- **Loot Manager accordion** – Collapse and expand to focus on what you need
- **Faster feedback** – See status messages pop up in the corner instead of inline
- **Version info** – Know what version you're running right in the header

## ⚡ Automatic Updates
Check for new versions right in the app. We'll notify you when updates are available.

## 🔧 Better Performance
Under the hood, we've cleaned things up for better stability and speed.

## 📥 How to Install
1. Download `RO Toolbox_0.1.1_x64_en-US.msi`
2. Run the installer and follow the prompts
3. The app will appear in your Start menu

That's it! Future versions will be easy to update too.
