# RO Toolbox – Release Notes

## v0.5.6 – Minor UI & Ergonomics Polish (2026-09-15)

### 🎨 UI & Layout Improvements
- **Launcher Header**: Replaced "Rose" text with the official Rose logo icon on the launcher header button.
- **Login Manager**: Positioned Export, Import, and Add action buttons absolutely in the top-right corner with Heroicons to prevent layout shifting.
- **Texture Replacer**: Cleaned up sub-service card background styling, eliminating legacy dual-color framing for unified panel surfaces.
- **Config Editor**: Constrained file selector to 50% width and aligned action buttons with search and save icons adjacent to it.
- **What's New Modal**: Complete redesign with categorized release sections, searchable keywords, version timelines, and styled markdown tags.

### 🔗 Useful Stuff Panel
- **ROSE Asset Hunter**: Added direct link with description to easily look up any in-game texture or model name.
- **Compact View & Internal Scrolling**: Optimized panel layout and card sizes with a custom internal scrollbar to prevent overall window scrolling.
- **Typography Polish**: Adjusted Useful Stuff link title and logo sizing for a cleaner, compact presentation.
