# RO Toolbox – Release Notes

## v0.3.9 – Compact mode, warnings, and foreground checks

### ✨ Improvements
- Added a config warning in the loot model manager when `show_dropped_item_name` is enabled, with a simple fix action to switch it back off.
- Kept the warning text cleaner and more focused, and limited it to the relevant profile states instead of showing everywhere.
- Added a ROSE running banner with a refresh action and re-checks whenever the app regains focus or comes back to the foreground.
- Improved launch-related status refreshes so the running-state banner updates reliably after quick launch and launcher actions.
