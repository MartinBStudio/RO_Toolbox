# RO Toolbox – Release Notes

## v0.4.2 – Small mode close confirmation sizing

### ✨ Improvements
- Removed background status polling and now refresh app status when RO Toolbox returns to the foreground.
- Made the small-mode close confirmation modal more compact for quick-launch mode.
- Package browser dropdowns now default to the currently installed package in loot models, combat text, user interface, and buff icons when available.
