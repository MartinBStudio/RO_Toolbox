# RO Toolbox – Release Notes

## v1.1.1 - Backup Flow Polish

This update adds support for displaying download progress.

### Resources

* **Resource download progress**: Loot models, combat text, UI themes, buff icons, and buff animations now show live
  download progress while updating.

### App

* **App download progress**: App updates showing download progress.

### Backup

* **Cleaner restore folders**: Restoring a backup no longer creates extra pre-restore folders in the backup location.

## v1.1.0 - ROSE Data Backup

This update adds support for backing up important ROSE Online user data, including game configuration and saved
accounts.

### Backup

* **ROSE Online config backup**: RO Toolbox can now back up your ROSE Online configuration data.
* **Account backup**: Saved ROSE Online accounts can now be included in the backup.
* **Backup provider selection**: Choose where your backup data is stored.
