Contribute resources

Add your own packs without changing the app

RO Toolbox reads public resource repositories directly. If you have a loot model, combat text pack, UI theme, buff icon set, or buff animation pack, contribute it to the matching repository and it can become available through the normal update flow.

Loot Models Combat Text UI Themes Buff Icons Buff Animations
1

Choose the repository

Open the resource repository that matches the type of pack you made.

2

Create a package folder

Follow the structure of existing profiles, add your resource files, and include preview images in `.preview` when possible.

3

Fill in metadata

Add the package name, author, version, date, description, and author or profile link when available.

4

Open a pull request

After review and merge, RO Toolbox users can receive the pack through resource updates.
